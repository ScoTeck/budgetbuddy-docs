# budgetbuddy-docs

Public documentation for the [Budget Buddy](https://github.com/ScoTeck/BudgetBuddy) iOS app: privacy policy and support/FAQ, published as a static site.

**Status: this repo is currently private.** Before Budget Buddy is submitted to the App Store, it must be:

1. Made public (Settings → General → Danger Zone → Change visibility)
2. Have GitHub Pages enabled (Settings → Pages → Source: Deploy from a branch → `main` → `/ (root)`)

Once public with Pages enabled, the site resolves at `https://scoteck.github.io/budgetbuddy-docs/`, matching the `NSPrivacyPolicyURL` / `NSSupportURL` already set in the app's `project.yml`.

Source content lives in the main BudgetBuddy repo at `marketing/Privacy-Policy.md` and `marketing/Support-FAQ.md` — update there first, then re-sync the HTML here.
