# budgetbuddy-docs

Public documentation for the [Budget Buddy](https://github.com/ScoTeck/BudgetBuddy) iOS app: privacy policy and support/FAQ, published as a static site on Vercel:

- https://budgetbuddy-docs.vercel.app/privacy.html
- https://budgetbuddy-docs.vercel.app/support.html

These match the `NSPrivacyPolicyURL` / `NSSupportURL` set in the app's `project.yml`. Redeploy steps are in the app repo's `DOCS_SITE.md`.

Source content lives in the main BudgetBuddy repo at `marketing/Privacy-Policy.md` and `marketing/Support-FAQ.md` — update there first, then re-sync the HTML here.
